# Перенос медиа в Cloudflare — 4 сентября 2026

## Текущий результат

Перенос выполнен частично: Tinify вернул HTTP 429, `TooManyRequests`, `Your monthly limit has been exceeded.` Последняя проверка: Compression-Count 506.

- 485 исходных медиа перенесены в 425 уникальных файлов R2 (совпадающие результаты используют один объект) и проверены через публичные HTTPS-адреса `https://media.yapil.art/`.
- Для каждого проверены HTTP 200, Content-Type и SHA-256 полученных с публичного URL байтов. Для PDF и шрифтов дополнительно проверен CORS.
- 320 растровых изображений прошли Tinify и сохранены в настоящем WebP. SVG, PDF, видео, шрифты и ICO сохранены в исходных форматах.
- Ссылки заменены в рабочей копии. Это не публикация новой версии сайта на Vercel.
- Видеопостеры связаны с роликами явно, поскольку хеши изображения и видео различаются.
- Локальные исходники сохранены для обработки и восстановления. Их наличие в public само по себе не означает, что страницы продолжают использовать локальные URL.

## Блокировка

Осталось 710 изображений:

- 626 файлов обложек статей: 622 подключены к статьям, ещё 4 находятся в public без обнаруженных ссылок в собранных страницах.
- 84 полноразмерных растровых оригинала Tilda из архивного сайта Shanding.

Архивные растровые data-original пока сохранены на Tilda: локальные экспортированные файлы часто являются превью шириной 20 пикселей, и подмена ими оригиналов ухудшила бы качество. Локальные превью и полные SVG перенесены в R2.

Увеличьте лимит существующего аккаунта Tinify или укажите разрешённый действующий TINIFY_API_KEY через защищённое окружение/.env. Ключ не требуется передавать в чат.

## Продолжение

Скрипты читают ключи только из окружения/.env и сохраняют прогресс после каждого проверенного файла. Повторная обработка уже проверенных исходников с тем же SHA-256 пропускается.

```sh
node scripts/migrate-media.mjs --preflight
node scripts/migrate-media.mjs
python3 scripts/apply-media-urls.py
node scripts/migrate-media.mjs --plan
npm run build
npm run seo:verify
```

`--cached-only` продолжает загрузку сохранённых результатов Tinify и форматов, которым Tinify не требуется. `--plan` обновляет список оставшихся файлов без сетевых запросов.

- `media-manifest.json` — проверенные URL, контрольные суммы, размеры и способ обработки.
- `media-migration-pending.json` — полный список ожидающих обработки исходников.
- `src/data/media-urls.json` — таблица адресов для динамических ссылок Astro.
- `.cache/media-migration/` — локальные результаты Tinify и журналы, не включаются в Git.
