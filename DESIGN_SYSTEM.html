Модальные окна

Заявка на услугу — не диалоговое окно поверх контента, а полноэкранный оверлей на весь вьюпорт (fixed inset-0, w-screen h-screen), поверх шапки. Контент внутри выстроен в ту же 12-колоночную сетку: текст слева, форма справа. Есть также лёгкий превью-модуль, следующий за курсором до клика.

Бесшовные фоны страниц

Секции стыкуются без видимой границы: каждая следующая начинается с цвета, которым закончилась предыдущая. Швы прячутся в линейных и радиальных градиентах.

Hero — прозрачный, поверх WebGL-канваса #120908 → #181818
Услуги — линейный градиент #181818 → #121213 → #0b0b0c
Портфолио / Всячина — плоский монохром #0b0b0c
Контакты — радиальный акцент поверх монохрома radial rgba(253,75,50,.28) + linear → #4a1309
Футер — Ruixen-градиент, продолжает терракотовую растяжку #4a1309 → #0b0b0c

Анимация на обложке

Два независимых слоя движения: WebGL-шейдер фона (постоянный, автономный) и 3D-гироскоп текстового блока (реагирует на курсор/наведение на кнопку).

Поведение кнопки

4 независимых слоя (контейнер → 3D-платформа → текст → иконка), каждый со своей задержкой — эффект «каскадного разгона» вместо одновременного скейла.

Default

translateZ 42px, letter-spacing 0.01em

Hover / focus-visible

0ms контейнер, 90ms текст, 140ms стрелка — каскад

Active / Click

мгновенный сброс за 90ms — тактильный отклик

Disabled

opacity 0.7, transform/shadow сброшены
