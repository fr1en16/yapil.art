# SEO-статьи Yapil

Комплект из 624 редакционных черновиков: 24 исходных материала и ещё по 100 трендовых тем на каждую из шести услуг. Каждый файл содержит `title`, `description`, `h1`, основной и связанные запросы, текст объёмом 5–8 тысяч знаков, обложку с alt-текстом, внутреннюю ссылку на услугу и CTA на бриф.

В индексе остаются 24 вручную подготовленных материала. Ещё 600 автоматически собранных `trend-*` страниц имеют статус `draft`: перед публикацией нужно добавить автора, дату, иллюстрации или фрагменты реальных кейсов и провести фактическую проверку от лица Yapil.

Трендовая библиотека генерируется командой `npm run seo:generate` и проверяется командой `npm run seo:verify`. Методика отбора тем описана в [TRENDS_METHODOLOGY.md](TRENDS_METHODOLOGY.md), полный машинный реестр находится в `trend-library-manifest.json`.

## Перед публикацией

- Добавить реальные кейсы, изображения и наблюдения Yapil.
- Проверить цены, правовые и технические утверждения на дату публикации.
- Указать автора и редактора.
- Проверить Title и Description после анализа выдачи по основному запросу.
- Добавить ссылки на релевантные кейсы и соседние статьи.
- Публиковать постепенно и отслеживать запросы в Google Search Console.
